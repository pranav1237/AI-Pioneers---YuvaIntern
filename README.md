# AI Pioneers — YuvaIntern

A collection of Python projects completed as part of the AI/ML internship. The repository currently includes work on data cleaning and exploratory analysis, supervised machine learning, and clustering/model evaluation.

## Projects

### Task 1 — Data Cleaning and Exploratory Data Analysis
**File:** `task1.py`

Uses a local Titanic dataset at `data/Titanic-Dataset.csv` to explore and prepare passenger data.

- Inspects dataset structure, summary statistics, missing values, and duplicates.
- Fills missing ages with the median and missing embarkation ports with the mode.
- Removes the cabin column and duplicate rows, then drops selected identifier/text columns.
- Encodes categorical columns and standardizes Age and Fare.
- Visualizes survival counts, gender distribution, fare distribution, correlations, and feature relationships.
- Exports the cleaned dataset to `output/cleaned_titanic.csv`.

Make sure the input CSV exists at the path expected by the script and create the `output/` directory before running it.

### Task 2 — Supervised Machine Learning
**File:** `task2.py`

Explores regression and classification using real datasets.

- **Regression:** trains Linear Regression on the California Housing dataset and evaluates it with MAE, MSE, RMSE, and R².
- **Classification:** predicts Titanic survival using Logistic Regression, Decision Tree, Random Forest, and K-Nearest Neighbors (KNN).
- Uses train/test splits and preprocessing pipelines for missing values, scaling, and categorical encoding.
- Compares classification models using accuracy, precision, recall, and F1-score, and displays evaluation visualizations.

The California Housing dataset is loaded through scikit-learn, and the Titanic CSV is fetched from a public URL, so an internet connection is needed.

### Task 3 — Clustering and Model Evaluation
**File:** `task3.py`

Uses scikit-learn's Breast Cancer Wisconsin dataset to practise unsupervised learning and classification evaluation.

- Applies feature standardization.
- Compares K-Means clustering across several cluster counts and evaluates it with silhouette scores.
- Performs Agglomerative (hierarchical) clustering.
- Uses Principal Component Analysis (PCA) to reduce features to two dimensions for visualization.
- Trains Logistic Regression and Random Forest classifiers.
- Reports accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrices.
- Runs stratified cross-validation and GridSearchCV hyperparameter tuning.

## Requirements

Python 3.10 or newer is recommended. The scripts use:

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

Install the dependencies with:

```bash
python -m venv .venv
```

Activate the environment, then install the packages:

```bash
# Windows
.venv\\Scripts\\activate

# macOS/Linux
source .venv/bin/activate

pip install pandas numpy matplotlib seaborn scikit-learn
```

## Run the Projects

Run commands from the repository root:

```bash
python task1.py
python task2.py
python task3.py
```

Run each task separately. Task 1 expects the Titanic CSV at `data/Titanic-Dataset.csv`; Tasks 2 and 3 load their datasets from public sources or scikit-learn. Some scripts display plots interactively, so use an environment that supports Matplotlib windows or notebook output.

## Learning Outcomes

These projects provide practice with data inspection and cleaning, exploratory visualization, encoding and scaling, regression and classification, clustering, dimensionality reduction, model evaluation, cross-validation, and hyperparameter tuning.

> **Note:** This repository is for educational practice. Model metrics are produced when the scripts run and are not stated here as fixed results.
